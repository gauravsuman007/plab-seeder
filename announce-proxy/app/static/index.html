Ports

Public address

The address your reverse proxy serves for the announce port, for clients outside your network (a debrid service, a seedbox). Clients set to "hand out the public address" put it in their torrents instead of the LAN address. Test it first: the proxy asks that address for a one-time token and checks that the answer comes from this proxy.
